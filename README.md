# Экраны приложения «English Around» и их зоны ответственности
## Приложение состоит из 10 основных экранов. Гость может просматривать каталог, открывать карточки слов и распознавать предметы. Личный словарь, история, тренировки и прогресс доступны после авторизации.

### 1. Экран входа
Зона ответственности: авторизация пользователя.
Элементы экрана:
•	Поля «Электронная почта» и «Пароль».
•	Кнопка «Войти».
•	Ссылка «Зарегистрироваться».
•	Кнопка «Продолжить как гость».
•	Сообщение при неверных данных.
Use case: «Войти в приложение».
Переходы: в каталог после входа или выбора гостевого режима; на экран регистрации.

### 2. Экран регистрации
Зона ответственности: создание учётной записи.
Элементы экрана:
•	Поля «Имя», «Электронная почта», «Пароль», «Повтор пароля».
•	Кнопка «Зарегистрироваться».
•	Ссылка «Уже есть аккаунт».
•	Сообщения об ошибках заполнения и занятом адресе.
Use case: «Зарегистрироваться».
Переходы: в каталог после успешной регистрации; на экран входа.

### 3. Каталог слов
Зона ответственности: просмотр и поиск доступной лексики.
Элементы экрана:
•	Строка поиска.
•	Фильтры по темам: «Еда», «Дом», «Животные», «Транспорт».
•	Карточки с изображением, английским словом и русским переводом.
•	Кнопка перехода к распознаванию.
•	Сообщение «Слова не найдены» при пустом результате поиска.
Use case: «Просмотреть каталог слов», «Найти слово».
Переходы: на карточку выбранного слова; на экран распознавания.

### 4. Экран распознавания
Зона ответственности: получение фотографии, отображение результатов распознавания и выбор предмета.
Элементы экрана:
•	Кнопки «Сделать фото» и «Выбрать из галереи».
•	Область предварительного просмотра фотографии.
•	Кнопка «Распознать».
•	Рамки и английские названия найденных объектов.
•	Список найденных предметов для выбора.
•	Кнопки «Другое фото» и «Выбрать слово вручную».
•	Индикатор обработки и сообщение, если предмет не найден.
Use case: «Распознать предметы на фотографии», «Сделать или выбрать фотографию», «Выбрать нужный объект», «Выбрать слово вручную».
Переходы: на карточку выбранного предмета; в каталог в режиме ручного выбора слова.
Камера и выбор изображения открываются средствами устройства. Для авторизованного пользователя выбранный результат сохраняется в истории.

### 5. Карточка слова
Зона ответственности: подробное представление слова и его сохранение для изучения.
Элементы экрана:
•	Изображение предмета.
•	Английское название и русский перевод.
•	Тема слова.
•	Кнопка «Подробнее о слове».
•	После загрузки: транскрипция, определение, пример и кнопка воспроизведения аудио, если они доступны.
•	Кнопка «Добавить в мой словарь» для авторизованного пользователя.
•	Отметка «Уже в словаре» для сохранённого слова.
•	Предложение войти для сохранения слова — для гостя.
Use case: «Просмотреть карточку слова», «Получить дополнительную словарную информацию», «Добавить слово в личный словарь».
Переходы: на предыдущий экран; на экран входа по выбору гостя.
При ошибке внешнего сервиса карточка сохраняет основную информацию и предлагает повторить загрузку дополнительных сведений.

### 6. Личный словарь
Зона ответственности: просмотр и управление словами, сохранёнными пользователем.
Доступ: после авторизации.
Элементы экрана:
•	Список слов с изображениями и переводами.
•	Поиск по сохранённым словам.
•	Фильтры «Все», «Новые», «Изучаю», «Изучено».
•	Действие «Удалить из словаря».
•	Кнопка «Начать тренировку».
•	При пустом словаре — предложение добавить слова из каталога или по фотографии.
Use case: «Просмотреть личный словарь», «Удалить слово из личного словаря».
Переходы: на карточку слова; на экран тренировки; в каталог или к распознаванию.
Удаление требует подтверждения и удаляет слово только из личного словаря пользователя.

### 7. Экран тренировки
Зона ответственности: проверка знания сохранённых слов.
Доступ: после авторизации.
Элементы экрана:
•	Номер текущего вопроса и общее количество вопросов.
•	Изображение предмета.
•	Варианты английского названия.
•	Сообщение о правильном или неправильном ответе.
•	Кнопка «Следующий вопрос».
•	Кнопка завершения тренировки.
Use case: «Пройти тренировку».
Переходы: на экран результата после последнего вопроса; в личный словарь при досрочном выходе.
Если слов недостаточно, приложение сообщает об этом до запуска тренировки и предлагает пополнить словарь.

### 8. Экран результата тренировки
Зона ответственности: представление итогов завершённой тренировки.
Доступ: после авторизации.
Элементы экрана:
•	Число правильных ответов и общее количество вопросов.
•	Процент правильных ответов.
•	Слова, в которых были допущены ошибки.
•	Статус сохранения результата.
•	Кнопки «Повторить тренировку», «Мой словарь», «Посмотреть прогресс».
Use case: «Сохранить результат тренировки» — выполняется автоматически после её завершения.
Переходы: на новую тренировку; в личный словарь; на экран прогресса.
При ошибке сохранения приложение показывает сообщение и предоставляет возможность повторить сохранение.

### 9. История распознаваний
Зона ответственности: доступ к ранее выбранным результатам распознавания.
Доступ: после авторизации.
Элементы экрана:
•	Список распознанных слов с изображениями из каталога.
•	Дата и время распознавания.
•	Английское название и русский перевод.
•	При отсутствии истории — кнопка «Распознать первый предмет».
Use case: «Просмотреть историю распознаваний».
Переходы: на карточку слова; на экран распознавания.

### 10. Профиль и прогресс
Зона ответственности: отображение учебной статистики и управление текущим сеансом.
Доступ: после авторизации.
Элементы экрана:
•	Имя и электронная почта пользователя.
•	Количество слов в личном словаре.
•	Количество изученных слов.
•	Число завершённых тренировок.
•	Общая доля правильных ответов.
•	Список результатов тренировок с датами.
•	Кнопка «История распознаваний».
•	Кнопка «Выйти».
Use case: «Просмотреть прогресс», «Выйти из приложения».
Переходы: в историю распознаваний; после выхода — в каталог в гостевом режиме.

### Общая навигация
Для авторизованного пользователя нижняя панель содержит четыре раздела:
Каталог · Распознать · Мой словарь · Профиль
Для гостя:
Каталог · Распознать · Войти
Тренировка открывается из личного словаря, история — из профиля, карточка слова — из каталога, результатов распознавания, личного словаря или истории.
